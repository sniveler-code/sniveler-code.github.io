# 🚧 Dynamic Obstacles & Doors

Block and restore navigation at runtime **without re-baking**. Two mechanisms:

1. **Per-link override** — `SetLinkBlocked` blocks a single graph link (debris, a fallen crate).
2. **Tag masks** — `BnDoorComponent` + per-polygon tag masks handle door/water-style blocking by polygon tag (≤ 16 tags).

## `BnDynamicObstacleSystem.SetLinkBlocked`

```csharp
using SnivelerCode.BurstNav.Runtime.Systems;

// Main-thread only (debug-asserted).
// linkIndex is the index into the baked graph's Links array (0 .. Links.Length - 1)
// of the BnGraphData singleton. blocked: true = block, false = restore.
public static void SetLinkBlocked(World world, int linkIndex, bool blocked);
```

Thread contract: the method asserts the main thread in debug builds (a worker-thread call logs an error and does not crash). In release builds the assert compiles out — keep calls on the main thread.

## Doors & tag masks

Tags are assigned **at bake time** on `BnMeshAuthoring.PolygonTagMasks` (per-polygon bit mask, bit `i` = tag `i`, ≤ 16 tags). A link inherits the **union** of both polygons' masks, and is blocked when that mask intersects the runtime blocked mask:

```csharp
// Bake-time: tag the polygons (on BnMeshAuthoring, then re-bake).
mesh.PolygonTagMasks[12] = 1 << 0;   // tag 0 = "door A"
mesh.PolygonTagMasks[40] = 1 << 1;   // tag 1 = "water" (always blocked: never opened)

// Runtime (main thread, e.g. a MonoBehaviour.Update or another system):
// Door: an ECS entity whose Closed state drives tag 0.
SystemAPI.SetComponent(doorEntity, new BnDoorComponent { Tag = 0, Closed = true });  // close →
// links blocked, affected agents re-path within 1–2 frames
SystemAPI.SetComponent(doorEntity, new BnDoorComponent { Tag = 0, Closed = false }); // open →
// failed agents re-requested
```

`BnDoorComponent` fields:

| Field | Type | Meaning |
|---|---|---|
| `Tag` | `ushort` | Door tag (bit index, 0–15). |
| `Closed` | `bool` | `true` → the tag is blocked this frame. |

Any ECS entity with `BnDoorComponent` in the world contributes to the blocked mask. A link is blocked when its tag mask intersects the blocked mask, **or** when its per-link override bit is set via `SetLinkBlocked`.

## How re-pathing works

`BnDynamicObstacleSystem` runs before pathfinding every frame:

1. Merges door tag masks into `BnObstacleState.BlockedTagMask`.
2. Tracks per-link overrides in `BnObstacleLinkFlags`.
3. On frames where anything changed, schedules a Burst job that marks affected `Ready` agents (corridors containing a changed link) as `Requested` — and re-requests `Failed` agents on unblock frames.

Steady state costs zero allocations; the affected-agent scan uses a hash set for large change sets and a linear scan for small ones (threshold-internal).

## Auto-managed state singletons

Both singletons are created on first use — nothing to set up:

```csharp
public struct BnObstacleState : IComponentData      // auto-created on first change
{
    public ushort BlockedTagMask;   // OR of Closed BnDoorComponent.Tag values
    public int OverrideVersion;     // bumped on any block/unblock (version tag)
}

public struct BnObstacleLinkFlags : IComponentData  // created on first SetLinkBlocked
{
    public NativeArray<ushort> Value;   // per-link flags, bit 0 = blocked
}
```
