# 🧩 Components & Systems

All agent components live in `SnivelerCode.BurstNav.Runtime.Components`; the four systems in `SnivelerCode.BurstNav.Runtime.Systems`.

## Path state

```csharp
public enum BnPathState : byte
{
    Idle = 0,        // no active request
    Requested = 1,   // waiting for a corridor
    Ready = 3,       // corridor assigned, steering active
    Failed = 4       // search failed; stays until a new SetDestination
}

public struct BnPathStateData : IComponentData { public BnPathState Value; }
```

## Agent components

```csharp
public struct BnNavDestination : IComponentData { public float3 Position; }

public struct BnAgentSteering : IComponentData
{
    public float3 UltimateTarget;     // final destination (set by SetDestination)
    public float Speed;
    public float RotationSpeed;
    public float StopDistance;
    public ushort CurrentPolyIndex;   // corridor progress
    public ushort WindowSize;         // ORCA window (8 when authored)
}

public struct BnOrcaState : IComponentData
{
    public float2 Velocity;           // resolved velocity (integrated in XZ)
    public float2 DesiredVelocity;
    public float MaxSpeed;
    public float TimeHorizon;
    public ushort NeighborCount;
}

public struct BnAgentCollider : IComponentData
{
    public float Radius;              // ORCA disk radius
    public float AvoidanceWeight;
}

public struct BnPolyBuffer : IBufferElementData   // DynamicBuffer: the corridor
{
    public int PolyID;                // polygon index in the blob graph
    public int LinkIndex;             // link used to enter this polygon
}

public struct BnPathRequestTag : IComponentData, IEnableableComponent { }
// Disabled on Idle agents; enabled by SetDestination / right-click command /
// internal re-requests. The steering pipeline only integrates agents that
// carry an enabled tag.
```

`BnPathRequestTag` is an `IEnableableComponent` — toggling it flips a chunk bitmask in O(1) without moving entities between chunks.

## Authoring components

```csharp
// BnMeshAuthoring : MonoBehaviour — the bake source.
// CachedVertices / CachedIndices — NavMesh triangulation (refreshed only via the
//   context menu "Bake NavMesh Data to Authoring").
// GridCellSize   — float, 2.0 default. <= 0 = auto (median of longest triangle edge).
// HpaEnabled     — bool, true. Bake the HPA* cluster graph.
// HpaDistanceThreshold — float, 500.0. Paths shorter than this use flat A*.
// PolygonTagMasks — int[] (per-polygon tag mask; bit i = tag i, <= 16 tags).

// BnAgentAuthoring : MonoBehaviour — agent template.
// Speed 5.0 / RotationSpeed 10.0 / StopDistance 0.5 (defaults).
```

Bake rules of note:

* The `Baker` runs when the scene is baked into the world (entering Play) and is skipped entirely if `CachedIndices` is empty.
* Vertex welding uses a 1 mm integer key; polygon links carry portal endpoints, center-distance cost, and the tag-mask union.
* Grid cap: if `cols × rows` would exceed 4,000,000 cells the cell size is doubled (with a warning) until it fits.
* HPA cap: more than 65,534 clusters → HPA data is skipped (warning), flat A\* is used at runtime.
* Output: `BnGraphData { Graph = BlobAssetReference<BnBlobMeshGraph> }` singleton entity.

## Graph singleton

```csharp
public struct BnGraphData : IComponentData
{
    public BlobAssetReference<BnBlobMeshGraph> Graph;
}
```

Created by the `BnMeshAuthoring` baker. Systems without a `BnGraphData` singleton in the world do nothing. The blob layout is documented in [Mesh Graph Blob Format](7.-blob-format.md).

## Spatial constants

```csharp
// SnivelerCode.BurstNav.Runtime.Core.BnSpatialGrid
public const float CellSize = 2.0f;                // agent-neighborhood hash cell (m)
public const float MaxAgentRadius = CellSize * 0.5f; // 1 m
```

Agents with `Radius > MaxAgentRadius` receive a warning (not clamped).

## Systems (order & role)

| System | Group | Role |
|---|---|---|
| `BnCommandSystem` | `SimulationSystemGroup`, before `BnPathfindingSystem` | Optional right-click command (legacy input manager) — see [How It Works](3.-how-it-works.md). |
| `BnDynamicObstacleSystem` | before pathfinding | Door/link block merging + affected-agent re-requests. |
| `BnPathfindingSystem` | `SimulationSystemGroup` | Serves `Requested` agents (capped throughput), flat/HPA\* search, corridor publication. |
| `BnSteeringSystem` | after pathfinding | Funnel + ORCA + XZ integration + corridor containment clamp. |

## Editor verification harnesses

Compiled only when the project defines `BN_INCLUDE_HARNESS` (see [Installation & Requirements](1.-installation-and-requirements.md)). Menu: `BurstNav/…`:

* `BurstNav/Run All Checks` — every check in one pass (`-executeMethod SnivelerCode.BurstNav.Editor.BnHarnessRunner.RunAll`)
* `BurstNav/TICKET-01: spatial grid (synthetic | baked scene)`
* `BurstNav/TICKET-02: corridor clamp DoD#1…#3`
* `BurstNav/TICKET-03: ORCA head-on / crowd / determinism`
* `BurstNav/TICKET-05: dynamic obstacle DoD#1…#2 / door tag`
* `BurstNav/P01…P10: …` — per-audit-finding regression checks

Each check is a static method, individually runnable headless:

```
Unity -batchmode -quit -projectPath <p> \
  -executeMethod SnivelerCode.BurstNav.Editor.BnSpatialGridTests.<RunMethod>
```

An NUnit EditMode test assembly also ships in the package (runs via the Unity Test Runner).
