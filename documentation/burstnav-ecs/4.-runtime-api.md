# 📡 Runtime API — BnAgents

The public runtime surface is intentionally small: one factory class (`BnAgents`), one config struct (`BnAgentConfig`), and the dynamic-obstacle API ([Dynamic Obstacles & Doors](5.-dynamic-obstacles-and-doors.md)).

Namespace: `SnivelerCode.BurstNav.Runtime.Components`.

## `static class BnAgents`

Main-thread only (both `Create` overloads and `SetDestination` mutate ECS storage directly, schedule no jobs, and are safe to call between frames — e.g. in `Update` or a system's `OnUpdate`). For **mass spawning** (hundreds per frame) use an `EntityCommandBuffer` instead of looping `Create`.

```csharp
// Authoring defaults: Speed 5, RotationSpeed 10, StopDistance 0.5,
// Radius 0.5, AvoidanceWeight 1, TimeHorizon 5.
public static Entity Create(World world, float3 position);

// Explicit configuration.
public static Entity Create(World world, float3 position, in BnAgentConfig cfg);

// Request a path: sets BnNavDestination.Position, state → Requested,
// enables BnPathRequestTag. Main-thread only.
public static void SetDestination(World world, Entity agent, float3 position);
```

## `struct BnAgentConfig`

| Field | Type | Meaning |
|---|---|---|
| `Speed` | `float` | Max steering speed (m/s). |
| `RotationSpeed` | `float` | Visual rotation slerp rate. |
| `StopDistance` | `float` | Distance to target considered "reached". |
| `Radius` | `float` | ORCA disk radius (m). Keep ≤ `BnSpatialGrid.MaxAgentRadius` (1 m) to avoid warnings. |
| `AvoidanceWeight` | `float` | ORCA preference weight for avoiding other agents. |
| `TimeHorizon` | `float` | ORCA time-to-collision horizon (s). |

`public static BnAgentConfig Default()` returns the authoring defaults. Note: `BnAgentConfig` is a plain struct **without field initializers** — a `default`-constructed instance is all zeros, so use `BnAgentConfig.Default()` when you want the authoring values.

## The 8 components created by `BnAgents.Create`

Identical (component-for-component) to what the `BnAgentAuthoring` baker produces:

| Component | Initial value |
|---|---|
| `LocalTransform` | spawn position, identity rotation |
| `BnAgentSteering` | config values, `WindowSize = 8` |
| `BnPathStateData` | `Idle` |
| `BnOrcaState` | `MaxSpeed = cfg.Speed`, `TimeHorizon = cfg.TimeHorizon` |
| `BnNavDestination` | spawn position |
| `BnAgentCollider` | `Radius = cfg.Radius`, `AvoidanceWeight = cfg.AvoidanceWeight` |
| `BnPolyBuffer` | empty dynamic buffer (the corridor) |
| `BnPathRequestTag` | **disabled** until the first destination |

The steering pipeline only integrates agents that carry an **enabled** `BnPathRequestTag` — a hand-built agent missing any of the 8 components misbehaves silently (frozen, no error). That's why `BnAgents.Create` exists.

## Behavior notes

* Agents start `Idle` and move only after `SetDestination`.
* The spawn position must be within one spatial-grid cell (2 m) of the mesh, otherwise the first request ends in `BnPathState.Failed`.
* `SetDestination` is the single documented way to request a path at runtime — callers never need to know the tag mechanics.
* Reaching the destination (within `StopDistance`) returns the agent to `Idle`.
