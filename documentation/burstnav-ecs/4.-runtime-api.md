# 📡 Runtime API

Everything below lives in the `BurstNav` namespace and compiles against `SnivelerCode.BurstNav.Runtime`. The API is deliberately small: six agent components, one graph component, two static solvers (`BnAStar`, `BnFunnel`), two systems and five jobs.

## 🧾 Components at a glance

| Component | Kind | Fields |
|---|---|---|
| `BnAgentSteering` | `IComponentData` | `Position: float3`, `Velocity: float3`, `DesiredVelocity: float3`, `MaxSpeed: float`, `Radius: float`, `PathProgress: float`, `PathLength: float`, `WaypointIndex: int`, `Flags: BnAgentFlags` |
| `BnAgentPath` | `IComponentData` | `PathIndex: int`, `WaypointCount: int`, `Status: BnPathStatus` |
| `BnPathWaypoint` | `IBufferElementData` | `Position: float3`, `ExitPoint: float3`, `PolyIndex: int`, `LinkIndex: int` |
| `BnAgentPathRequest` | `IComponentData` | `Start: float3`, `Target: float3`, `RequestId: uint`, `StartPoly: int`, `TargetPoly: int`, `Status: BnPathStatus` |
| `BnAgentSteeringActive` | `IComponentData`, `IEnableableComponent` | none — chunk enable bit |
| `BnAgentPathRequestPending` | `IComponentData`, `IEnableableComponent` | none — chunk enable bit |
| `BnBlobMeshGraph` | `IComponentData` | `Value: BlobAssetReference<BnMeshGraphBlob>` |

Active bits are the point: enabling or disabling an `IEnableableComponent` flips a bit in the chunk mask and moves **no entity between archetypes**, so a toggle costs nothing in memory or chunk churn.

## 🔁 The request lifecycle

```csharp
// 1. Write the request (main thread or a system, before BnPathfindingSystem)
var request = entityManager.GetComponentData<BnAgentPathRequest>(agent);
request.Start = currentPosition;
request.Target = destination;
request.TargetPoly = -1;                 // -1 = snap to the nearest polygon
request.Status = BnPathStatus.Pending;
request.RequestId++;
entityManager.SetComponentData(agent, request);

// 2. Arm the toggle
entityManager.SetComponentEnabled<BnAgentPathRequestPending>(agent, true);
```

| Step | Who does it | Result |
|---|---|---|
| Write target + arm toggle | gameplay | `BnAgentPathRequest.Status = Pending` |
| `BnPathfindJob` | `BnPathfindingSystem` | snaps `Start`/`Target` to polygons, runs A*, fills the buffer |
| Toggle playback | end-of-frame ECB | `BnAgentPathRequestPending` disabled again |
| `BnPathStatus.Ready` | path slot | corridor is followable |
| `BnSteeringStateJob` | `BnSteeringSystem` | re-enables `BnAgentSteeringActive` for followable agents |

| `BnPathStatus` | Meaning |
|---|---|
| `None` | No request issued yet (freshly baked agent). |
| `Pending` | Request armed, not yet resolved. |
| `Ready` | A corridor is available and followable. |
| `Partial` | Reserved for a partial result; Free never produces one. |
| `Failed` | Empty graph, unreachable target, or exhausted budget. Corridor cleared. |

> ⚠️ **`RequestId` is yours alone.** `BnPathfindJob` copies it through untouched and never compares it, so the pipeline cannot detect a stale result for you. If you issue overlapping requests, compare the id after the status becomes `Ready`.

## 🧠 Running a search yourself

`BnAStar.FindPath` is a public static and Burst-callable:

```text
bool BnAStar.FindPath(ref BnMeshGraphBlob graph, int startPoly, int targetPoly,
                      ref BnPathScratchpad scratch, int maxIterations)
```

```csharp
public void Search(ref BnMeshGraphBlob graph, ref BnPathScratchpad scratch, int start, int target)
{
    if (!BnAStar.FindPath(ref graph, start, target, ref scratch, 4096))
    {
        var reason = scratch.Status; // Unreachable / BudgetExhausted / InvalidInput / CapacityExceeded
        return;
    }

    for (var index = 0; index < scratch.PathCount; index++)
    {
        var polygon = scratch.GetPathPolygon(index);
        // use the polygon id
    }
}
```

Ownership rules for the scratchpad:

* `BnPathScratchpad.Create(polygonCapacity, allocator)` allocates once; `EnsureCapacity(polygonCount, allocator)` grows only when the graph outgrows it.
* `Dispose()` must run exactly once. `Dispose(JobHandle)` releases the arrays after the handle completes — that is how `BnPathfindingSystem` retires a resized scratchpad without stalling the main thread.
* The scratchpad is **not thread-safe** while a search mutates it. One search at a time per scratchpad.

Filtered overloads exist on the same method for searches you run yourself:

```text
bool FindPath(ref BnMeshGraphBlob graph, int startPoly, int targetPoly, ref BnPathScratchpad scratch,
              BnLinkFilter filter, int maxIterations)
bool FindPath(ref BnMeshGraphBlob graph, int startPoly, int targetPoly, ref BnPathScratchpad scratch,
              BnLinkFilter filter, NativeArray<ushort> linkTagMasks, int maxIterations)
```

`BnLinkFilter.PassThrough` (the default value) allows every link; a non-zero `IgnoreTagged` rejects every link with any tag bit; otherwise a link is rejected only when one of its tag bits is inside `BlockedTagMask`, and `AllowBlockedTags` waives that block. The Free systems always call the unfiltered overload.

## 🎯 Solving steering yourself

`BnFunnel` is the string-pulling solver used by `BnFunnelJob`:

```text
public static void Solve(ref BnAgentSteering steering, ref BnAgentPath path,
                         in DynamicBuffer<BnPathWaypoint> waypoints,
                         ref BnMeshGraphBlob graph, float deltaTime)
```

```csharp
// Inside a job, on chunk arrays:
BnFunnel.Solve(ref steering, ref path, in waypoints, ref graph, deltaTime);
```

| Overload pair | Use |
|---|---|
| `DynamicBuffer<BnPathWaypoint>` / `NativeArray<BnPathWaypoint>` | Same semantics; pick what your call site has. |
| With / without `deltaTime` | Without it, `deltaTime` is `0`, so the desired speed is the full `MaxSpeed`. |

Related statics:

| Method | Returns |
|---|---|
| `BnFunnel.AdvancePathProgress(ref steering, ref path, waypoints, ref graph, arrivalRadius)` | New waypoint index; also rewrites `PathProgress`/`PathLength`. |
| `BnFunnel.GetNextWaypoint(ref graph, corridor, startIndex, agentPosition, targetPosition)` | The next funnel corner as `float3`. |

All of them allocate nothing and own no memory. `Solve` and `AdvancePathProgress` write `steering` and `path.WaypointCount`; the waypoint buffer and the graph are read-only.

## 🧱 Creating agents from code

Without authoring components, create the same archetype:

```csharp
var archetype = BnAgentComponents.CreateAgentArchetype(entityManager);
var agent = entityManager.CreateEntity(archetype);

entityManager.SetComponentData(agent, BnAgentSteering.Idle(position, maxSpeed: 5f, radius: 0.5f));
entityManager.SetComponentData(agent, new BnAgentPath
{
    PathIndex = 0,
    WaypointCount = 0,
    Status = BnPathStatus.None,
});
entityManager.SetComponentData(agent, new BnAgentPathRequest
{
    Start = position,
    Target = position,
    RequestId = 0,
    StartPoly = -1,
    TargetPoly = -1,
    Status = BnPathStatus.None,
});
entityManager.SetBuffer<BnPathWaypoint>(agent);
entityManager.SetComponentEnabled<BnAgentSteeringActive>(agent, true);
entityManager.SetComponentEnabled<BnAgentPathRequestPending>(agent, false);
```

`BnAgentSteering.Idle(position, maxSpeed, radius)` returns zero velocity, `BnAgentFlags.None` and no path. Call `CreateAgentArchetype` during world setup, never per frame.

## 🚩 Flags and progress

| Member | Meaning |
|---|---|
| `BnAgentFlags.Following` | Active path following. |
| `BnAgentFlags.Arrived` | Final waypoint reached; `DesiredVelocity` is zero. |
| `BnAgentFlags.Blocked` | Reserved for gameplay — no Free code sets or reads it. |
| `BnAgentSteering.HasPath` | `PathLength > 0 && (Flags & Following) != 0`. |
| `BnAgentSteering.NormalizedProgress` | `PathProgress / PathLength` saturated to 0..1, or 0 without a path. |
| `BnAgentPath.IsFollowable` | `WaypointCount > 0 && (Status == Ready || Status == Partial)`. |

Both enums are `byte`-backed so the containing structs stay blittable and compact.

## 📦 Reading the graph

| Member | Returns |
|---|---|
| `PolygonCount`, `LinkCount`, `VertexCount` | Pool sizes. |
| `GetPolygonCenter(int id)` | `float2` centre. |
| `GetPolyLinkOffset(int id)`, `GetPolyLinkCount(int id)` | The polygon's link slice. |
| `GetPolyLink(int id, int index)` | `BnLinkData` (`PortalLeft`, `PortalRight`, `Target`, `Cost`). |
| `GetNeighborCount(int id)`, `GetNeighbor(int id, int index)` | Neighbour id. |
| `GetVertex(int index)` | `float2` vertex. |

The blob is immutable and safe to read from parallel jobs without a job dependency of its own.
