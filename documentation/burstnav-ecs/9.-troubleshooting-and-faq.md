# 🚑 Troubleshooting & FAQ

## 🔍 Agent does not move

Work through this list in order — it covers every cause we know of.

| # | Check | Fix |
|---|---|---|
| 1 | Is there exactly one `BnBlobMeshGraph` with `Value.IsCreated`? | Bake the graph in a SubScene, or call `BnMeshAuthoringBaker.BuildGraph` once at startup. |
| 2 | Does the agent carry all six components? | Use `BnAgentAuthoring` or `BnAgentComponents.CreateAgentArchetype`. |
| 3 | Is `BnAgentPathRequestPending` enabled? | Enable it after writing a target — a freshly baked agent has it off by design. |
| 4 | Did you write a `Target` different from `Start`? | The baker sets both to the spawn position. |
| 5 | Are `BnPathfindingSystem` and `BnSteeringSystem` present and enabled? | Check **Window → Entities → Systems**; in a custom world, create both inside `SimulationSystemGroup`. |
| 6 | Is `BnAgentSteeringActive` enabled? | `BnSteeringStateJob` turns it on when a path becomes followable; a manual `false` keeps the agent frozen. |
| 7 | Is Burst enabled with no job safety errors? | Fix the first console error before anything else. |

## ❌ `BnAgentPath.Status` is `Failed`

Three causes, in order of likelihood:

| Cause | Symptom | Fix |
|---|---|---|
| No route between the resolved polygons | `StartPoly`/`TargetPoly` are valid but disconnected | Check the graph actually connects those regions; a grid graph with `CellsX = 1` cannot go sideways. |
| Budget exhausted | `scratch.Iterations == MaxIterations` | Raise `BnPathfindingSystem.MaxIterations`. |
| Empty graph | `PolygonCount == 0`, so both snaps return `-1` | The bake produced nothing: `CellsX`/`CellsY` are clamped to at least 1, so check that the entity was actually baked. |

Remember that a failed search **clears the corridor** — the agent stops rather than following a partial path. That is intentional.

## 🧭 The agent walks in a straight line through walls

| Cause | Fix |
|---|---|
| Z was used as the navigation plane | Pathfinding is XZ only: put the level on XZ and use Y for height. |
| The graph sits somewhere else than the level | `Origin` and `CellSize` of `BnMeshAuthoring` must match the visual layout. |
| Corridor waypoints were edited by gameplay | Never write `BnPathWaypoint` or `PathProgress`; both are owned by the pipeline. |

## 👥 Agents pass through each other

That is the documented behaviour. `KinematicBypassJob` copies `DesiredVelocity` into `Velocity` and reads no neighbour data, so Free has no separation stage. Use spaced spawn points, one-way lanes, staggered start times, or replace the steering system — see [Limitations & Scope](5.-limitations-and-scope.md).

## 🚧 Moving obstacles are ignored

The graph is an immutable blob and there is no obstacle store. Rebuild the blob for a new level state, or keep obstacles out of the walkable graph. There is no push-out when an agent overlaps a blocker.

## 🚪 Doors do not close

Free links carry no tags and the systems always run the unfiltered search. Enforce access in gameplay before issuing a request, or write a custom job around `BnAStar.FindPath`'s filtered overloads.

## 🧩 Nothing runs after adding a second graph

Both systems require a **single** `BnBlobMeshGraph`. With two, `TryGetSingleton` fails and the systems early-out — silently. Check the world for duplicate baked navmesh objects, including graphs imported with a sample.

## 📦 Sample cannot be found or opens with missing scripts

| Symptom | Fix |
|---|---|
| No sample in the Samples tab | Confirm the package version is `1.1.0` and that `package.json` lists the sample; refresh Package Manager. |
| Missing script references | Keep the generated `Scripts` folder and its `.asmdef` intact — it references `SnivelerCode.BurstNav.Runtime`. |
| Scene opens with missing scripts | Delete `Assets/Samples/BurstNav Free`, reimport from the Samples tab, reopen the scene. |
| `Samples~` is not under `Assets` | Expected — the folder is hidden by design until imported. |
| Gizmos are invisible | Select the `Gizmos` object and enable Gizmos in the Scene view toolbar; drawing is a scene aid only. |

## 🧪 Tests do not appear in the Test Runner

Package tests compile only when the package is listed under `testables`:

```json
{
  "testables": ["sniveler-code.dev.burstnav-ecs"]
}
```

Then run `SnivelerCode.BurstNav.Tests.EditMode` or `SnivelerCode.BurstNav.Tests.PlayMode`.

## ❓ FAQ

**Does Free support slopes, stairs or multiple floors?**
No. Navigation is XZ only; the pipeline never modifies agent Y. Vertical movement is your gameplay's job, and a multi-floor level flattens into one plane.

**Can I use a custom mesh instead of the grid?**
Yes, by writing your own `BlobBuilder` code that produces a valid `BnMeshGraphBlob` — see the invariants in [Mesh Graph Blob Format](7.-blob-format.md). `BnMeshAuthoring` itself only emits grids.

**Can I have two graphs and switch between them?**
Not through the Free systems: they require exactly one singleton, and replacing the blob while searches are in flight is unsupported. Build one graph per level.

**Is this a NavMesh replacement?**
For static, moderate-size levels with per-agent movement, yes. It is not a replacement for crowd simulation, dynamic obstacles or off-mesh links.

**Do I need a SubScene?**
No. Both samples build the graph from code at Play start (`BnMeshAuthoringBaker.BuildGraph`). A SubScene is just the convenient path for level designers.

**Is the result deterministic?**
Yes, given the same graph, the same requests and the same frame delta. `BnPathfindJob` is single-threaded over a stable polygon ordering, and steering is per-agent with no shared state.

**What happens if a corridor is longer than 16 polygons?**
The `BnPathWaypoint` buffer spills from inline storage to the heap once for that agent. Paths of 16 or fewer polygons are allocation-free.

**Does `RequestId` cancel a stale request?**
No. It is copied through untouched; compare it yourself if you issue overlapping requests.

**Which Unity versions are supported?**
Unity 2022.3 and newer with Entities 1.x. It is verified in Unity 6000.5.2f1 with `com.unity.entities` 6.5.0.
